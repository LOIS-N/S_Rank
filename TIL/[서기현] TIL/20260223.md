# 1. AI 미사용 창작물 저작권 관리 서비스

- 기획
    
    ## 크리에이터 원본 증명 플랫폼
    
    ---
    
    ### 한 줄 요약
    
    웹툰·일러스트 작가가 **저장만 하면 자동으로 블록체인에 원본이 기록**되는 서비스. 도용당했을 때 즉시 꺼낼 수 있는 증거를 만든다.
    
    ---
    
    ### 문제
    
    - 작가 54.6%가 저작권 침해 경험, 연간 피해액 4,465억 원
    - AI가 화풍 무단 학습하는 사례 급증
    - **근데 "내가 먼저 만들었다"를 증명할 현실적인 수단이 없음**
        - 저작권위원회 등록 → 한 달 걸리고 건당 2~4만 원
        - SNS 타임스탬프 → 법원에서 증거로 안 받아줌
        - Adobe C2PA → 국내 작가 대다수가 쓰는 클립스튜디오 미지원
    
    ---
    
    ### 블록체인이 어떻게 적용되는가
    
    `① 작가가 클립스튜디오에서 저장
    ② 플러그인이 파일 해시값(SHA-256) 자동 생성
       — 파일 내용이 1픽셀만 달라도 완전히 다른 값이 나옴
    ③ 해시값 + 작가 ID + 타임스탬프 → 폴리곤 블록체인에 기록
       — 등록 비용: 건당 10원 미만
    ④ 트랜잭션 ID 발급 → 누구나 조회 가능한 원본 증명서`
    
    핵심은 **파일 자체를 올리는 게 아니라 지문(해시값)만 기록**한다는 것. 원본이 유출될 위험이 없고, 한번 기록되면 수정·삭제 불가능하다. 도용 발생 시 "이 해시값은 이 날짜에 이 사람이 등록했다"는 걸 블록체인이 증명해준다.
    
    ---
    
    ### 왜 지금인가
    
    - AI 기본법 2026년 1월 시행 → "AI가 안 만든 작품"임을 증명하는 수요가 법으로 만들어짐
    - 블록체인 등록 비용이 처음으로 현실적 수준(건당 10원)이 됨
    - 클립스튜디오·이비스페인트를 지원하는 경쟁자가 아직 없음
    
    ---
    
    ### 수익 구조
    
    무료(월 10건) → Pro 월 5,900원(무제한) → B2B(플랫폼·게임사 API 연동)
