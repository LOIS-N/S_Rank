# 아이디어 구체화 시키기

- **자기계발 챌린지 플랫폼**
    
    투명성 증명이 아니라, **사용자의 행동을 강제하는 '경제적 게임 이론'**을 활용한 서비스입니다.
    
    - **문제 의식:** 인강 완강, 알고리즘 매일 풀기 등은 의지력이 부족해 실패하기 쉽습니다. 기존 앱들은 벌금이 있어도 운영자가 수동으로 관리하죠.
    - **블록체인 활용:** 사용자가 목표 달성을 위해 가상자산을 예치(Staking)합니다.
        - **성공 시:** 예치금 전액 반환 + 실패한 사람들의 예치금을 '상금'으로 배분받음.
        - **실패 시:** 예치금이 즉시 삭감(Slashing)되어 성공한 사람들에게 스마트 컨트랙트로 자동 전송됩니다.
    - **개발 포인트:** 외부 데이터(예: 백준/GitHub API)를 읽어와서 목표 달성 여부를 판단하는 **오라클(Oracle) 로직**과 상금을 분배하는 **수학적 알고리즘** 구현.
    - **사용자 이점:** "안 하면 돈 날린다"는 확실한 동기부여와 "잘하면 남의 돈을 번다"는 수익 구조.
    - **기술 활용(백엔드) :** 블록체인 + (스마트 컨트랙트) + { MQ + SSE  : 랭킹 시스템 도입 시}
    - 계획 달성 시 뱃지/순위등의 시스템을 도입해도 좋을 듯
    - 챌린지 인증 사진의 적절성을 다른 사용자들이 투표로 판별하는 시스템(DAO)
    - 챌린지 기록을 보여주는 달력을 만들어도 좋을 것 같음(ex: 런데이)
    - 루틴 달성 게임 해비티카 https://m.blog.naver.com/gas98/221941575558
