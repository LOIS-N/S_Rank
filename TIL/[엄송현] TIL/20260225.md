1. 블록체인 웹사이트 게임 및 아이템 거래
-간단하게 구현할 수 있는 게임 (뱀파이어 서바이벌 / 디펜스) => 플레이어가 상위권 랭크 도달을 목표로 플레이할 수 있게
-단계별로 게임 결과를 저장하고 나중에 플레이할 수 있게
-웹 서비스로 게임을 배포, 게임 내에서 사용하는 아이템을 NFT로 구현
-차별점: 무기/유닛 강화 후 판매 가능하게 할 예정 -> 강화도에 따라 가치가 달라짐
-강화된/강화되지 않은 아이템 모두 거래 가능하게
-게임 아이템을 거래할 때 이더리움 지갑을 사용해서 충전식 / 수수료 부과
-다른 게임들의 경우 아이템 교환 시스템이 구축된 서비스가 없어서 자체적으로 교환 시스템을 만들고 싶었다.

2. 뽑기합성, 도감, 시즌패스 게임
-개발자 키우기 타이쿤
-개발자 카드게임 => 합성 / 팀 빌딩 / 카드 등급제
-무료 에셋을 사용해서 게임을 제작하면 될 듯
-S등급 카드 -> NFT / 업적, 랭킹 달성 시 양도 불가 배지
-상호작용 => 랭킹제 정도

2-1. 싸피 키우기
-네이버 동물농장st의 개발자 키우는 게임
-현실 세계의 나와 연동된다는 느낌
-아이템 합성/뽑기/추천시 블록체인
-다른 사람들과의 상호작용은 채팅/경매
-발행률/드랍률 블록체인

3. 조각투자 플랫폼
-고가의 자산을 펀드처럼 나눠 부동산 투자 서비스
-지속적인 수입이 있는 자산을 대상
-스마트 컨트랙트를 사용해서 금액 지급
-회사와 개인간의 거래만 가능

5. 자기계발 챌린지
-기존 챌린저스앱과 유사한 구조 / 분야 미정
-인증했는데 제대로 된 기준대로 평가 안함 / 목표 실패시 운영자가 가져감
-달성률 %제 -> 100% / 80% 이상 / 80% 미만
-기준을 탄탄하게 세우기 / 실패한 사람의 돈을 가져가서 1/N
-인증 방식을 조사하고 확실히 검증할 수 있는 분야를 골라야 할 듯
-기록, 랭킹 시스템 / 익명으로 다른 사람들의 기록을 볼 수 있게 하는 교류 시스템
