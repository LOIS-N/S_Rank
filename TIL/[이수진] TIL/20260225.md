# 2. 회고
- **KEEP**
    - 팀 미팅으로 게임 아이디어 구체화 진행함
    - 사전 조사 진행
        - 포레스트 아일랜드
            - 방치형 자연&동물 키우기 게임
            - 음향, 디자인에 집중 (**귀엽다**)
            - 일일 보상
            - 퀘스트
            - 초반 가이드 있음
            - 자연 정화 ⇒ 보상
            - 및 동물 머리위에 하트 클릭
                - 하트 소비로 동물 레벨업
                
                    ⇒ 일정 레벨 달성 시 한마리 더 데려오고 하트 생산량 증가
                
                    ⇒ 하트로 새로운 동물 영입
                
            - 새로운 부지가 하나씩 오픈됨
            - 희귀동물 수집요소 추가
        - 공룡 박물관
            - 단순 반복으로 화석을 수집
            - 디스플레이 자리를 해금하면서 화석 발굴 난이도를 높임
            - 아이템 및 도구 업그레이드 
            - 중독성 있음
            - 2D 디자인
            - 단순한 디자인과 단순한 게임성
    - 추가되면 좋을 아이디어
        - 개발자마다 특성,속성 다르게
            - 특성 : 속도 ,  안정성 / 인성
            - 속성 : 금융 도메인 +3% , ERP +2%  등등
            - 같은 S급이라도 속성에 따라 능력치 다름
        - S급 개발자 트레이드( 포켓몬 트레이드 하듯이 )
        - 이벤트로 가끔 빌런 발생하기 + 장애 발생
            - 프론트에서 로그인 시간부터 랜덤한 시간 이후에 발생 시킬 수 있음, 단 레벨링 필요함(어떤 이벤트를 실행할지)
            - 빌런 못막으면 직원 한명 랜덤으로 이직함
